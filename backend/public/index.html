Estructura del Consolidado Nacional

El archivo exportado incluye la totalidad de las 165 sedes jurisdiccionales sin restricciones de sede con los siguientes campos:

Grupo Campos Exportados
Identificación ID, Tipo Documento, Número de Documento (DNI), Apellido Paterno, Apellido Materno, Nombres
Ubicación y Cargo Sede Regional, Sede Jurisdiccional, Local, Número de Aula, Cargo, Tipo Postulante, Turno
Control de Turnos Condición de Turno (1 o 2), Hora Programada 1, Marcación 1, Hora Programada 2, Marcación 2, Marcación Salida
Estado y Auditoría Fecha de Registro, Estado de Asistencia (Puntual, Tarde, NA), Observaciones, Usuario de Registro
