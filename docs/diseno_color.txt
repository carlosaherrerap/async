1. Paleta Cromática basada en Teoría del Color (Muted Analogous)Para prohibir los colores saturados, debes definir el espacio de color utilizando el modelo HSL (Hue, Saturation, Lightness). La clave para la elegancia es mantener la saturación por debajo del 30% en los colores de interfaz y usar armonías análogas (colores vecinos en el círculo cromático) para que no haya contrastes violentos.Prompt técnico: "Aplica una armonía de color análoga amortiguada (muted analogous) basada en la teoría del color de baja saturación. Queda estrictamente prohibido el uso de colores con saturación mayor al 30% en elementos estructurales y mayor al 60% en elementos de acento. No uses tonos cian artificiales como #008CA0. Configura el sistema con estos valores HSL exactos:Color Dominante (Fondo): HSL(210, 20%, 98%) -> Un blanco frío institucional.Color Secundario (Superficies/Tablas): HSL(0, 0%, 100%) -> Blanco puro para contraste limpio.Texto Primario y Títulos: HSL(222, 47%, 11%) -> Azul noche profundo, máxima legibilidad.Texto Secundario (Métricas/Datos): HSL(215, 16%, 47%) -> Gris pizarra neutro.Color de Énfasis (Accent sutil): HSL(215, 25%, 27%) -> Azul corporativo opaco, formal y elegante.Estados de Alerta (Semáforo FSM desaturado): Éxito en HSL(142, 70%, 25%) y Error en HSL(0, 75%, 45%). Nada de neones."


2. Teoría de Diseño: Jerarquía Visual y Leyes de la GestaltLa IA tiende a esparcir elementos sin orden. Debes obligarla a agrupar los datos del monitoreo de trabajadores y sedes usando principios psicológicos de diseño visual.Prompt técnico: "Aplica la Ley de Proximidad de la Gestalt para estructurar el dashboard: los datos de un mismo trabajador o sede deben agruparse en contenedores claros, utilizando el espacio en blanco (unidades de 4px/8px/16px) como el principal separador, no líneas gruesas. Establece una escala tipográfica estricta para garantizar la Jerarquía Visual: los números de las estadísticas principales deben medir 24px (Semibold), los títulos de sección 14px (Medium) y los datos de las tablas 13px (Regular). El contraste de tamaño debe guiar el ojo del usuario sin necesidad de usar colores llamativos."

Equilibrio, Peso Visual y Simetría FuncionalEn una app de software (SaaS), el peso visual debe estar balanceado para no cansar al usuario que opera la plataforma en tiempo real.Prompt técnico: "El diseño debe seguir un equilibrio asimétrico funcional. El menú lateral izquierdo (sidebar) debe tener un peso visual ligero (fondo idéntico al fondo general o blanco, con iconos lineales finos). El panel central (dashboard) debe concentrar el peso visual en los datos analíticos a través de tipografía limpia. Distribuye los elementos en una rejilla de alineación estricta de 12 columnas (Grid System) con un espacio entre columnas (gutter) de 24px. Ningún elemento decorativo o gráfico debe competir en peso visual con las métricas de gestión en tiempo real."
